# `@deepseek-ai/dsh-memory`

[English](README.md) | 中文

持久化审阅记忆的服务定义。每个操作都明确指定规范项目路径或全局作用域；标识符和修订号可防止跨作用域及过期写入。提案携带证据、可信度、时间有效期和显式矛盾链接。

## 模型体验

### 直接模型上下文

#### 模型看到的内容

没有直接内容。此服务定义不注册提示词、schema、结果或模型请求。

#### Token 影响

直接 token 为零；Consumer 负责加入模型上下文的任何检索记忆。

#### KV 缓存影响

不会直接失效；Consumer 负责加入模型上下文的任何检索记忆。

## 已知限制与延后工作

- 运行时只选择一个 provider。在有当前 Consumer 需要明确排序语义之前，不支持跨 provider 联邦。
