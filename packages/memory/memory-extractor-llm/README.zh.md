# `@deepseek-ai/dsh-memory-extractor-llm`

[English](README.md) | 中文

在已完成的 `turn/end` 到达会话持久化后异步提取项目记忆。有界队列在调度前记录并刷新精确辅助请求，随后记录精确组装响应和提案标识符。超时、取消、Provider 失败、格式错误和队列饱和会独立结算，不会使父级轮次失败。卸载会中止并等待活动调用。

## 模型体验

### 辅助提取请求

#### 模型看到的内容

配置的辅助模型接收一段固定提取指令和已完成轮次持久事件的 JSON 数组。它返回严格 JSON 提案，并且不接收工具。

#### Token 影响

每个完成轮次后最多产生一个独立有界请求。`maxInputBytes`、`maxOutputTokens` 和 `maxProposals` 限制完整请求和接受结果；提取语句不会进入主 agent 上下文。

#### KV 缓存影响

与主 agent 请求独立。固定系统指令保持前缀稳定；已完成轮次事件 JSON 随请求变化。

## 已知限制与延后工作

- 自动提取只创建项目提案。把提取事实提升为全局记忆始终是显式、经批准的审阅操作。
