# `@deepseek-ai/dsh-memory-sqlite`

[English](README.md) | 中文

持久化审阅记忆的 SQLite 服务 Provider。配置的绝对路径使用单调递增、应用专属的 schema 创建；旧版、外部或非空未版本化数据库会失败关闭。比较并交换变更和取代操作均在事务中执行。保留策略只删除过旧且已拒绝或已取代的项目记录；全局删除仍由批准机制拥有。

## 模型体验

### 直接模型上下文

#### 模型看到的内容

没有直接内容。此存储 Provider 不注册提示词、schema、结果或模型请求。

#### Token 影响

直接 token 为零；Consumer 负责加入模型上下文的有界记录。

#### KV 缓存影响

不会直接失效；Consumer 负责加入模型上下文的有界记录。

## 已知限制与延后工作

- 搜索目前使用 SQLite 子串匹配。当实测语料规模需要时，可在服务定义后替换为排序全文搜索。
