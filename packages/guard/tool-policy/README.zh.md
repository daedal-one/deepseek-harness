# dsh-tool-policy

[English](README.md) | 中文

`ctx.toolPolicy` 是与提供者无关的授权服务。提供者以稳定标识注册；部署可以配置一个有序集合，也可以省略它以评估所有已注册提供者。重复标识和缺失的已配置提供者会直接失败。

## 服务

`evaluate(request)` 接收不可变的工具身份、JSON 参数、调用代理和取消信号。所有选定提供者会并行运行。不支持该工具的提供者返回 `undefined`；一个受支持裁决会直接通过，重叠裁决则按 `deny` 高于 `ask`、`ask` 高于 `allow` 的顺序保守合并，并保留最高风险、合并后的有界分类与意见。提供者负责解释具体工具，并必须保留调用方取消语义。

注册由提供者插件的 effect 所有。卸载提供者会移除注册，不保留过期实现。

## 持久事件

`tool-policy/classifier-request` 在模型调用前记录完整且有界的辅助请求。`tool-policy/decision` 记录提供者和最终结果，不复制 `tool/call` 已保存的原始参数。不变量伴随插件要求事件位于对应调用之后且处于同一开放轮次。

## 模型体验

### 条件工具结果

#### 模型看到什么

服务不添加提示词或工具模式。消费者决定 `evaluate()` 裁决如何改变执行反馈。

#### Token 影响

分类调用消耗配置的辅助模型预算。持久审计事件不进入模型历史。

#### KV 缓存影响

服务不修改主请求，因此不会使其 KV 缓存前缀失效。

## 已知限制和延后工作

- 插件可以热重载，因此在每次求值时检查提供者可用性。
