# dsh-tool-policy-shell

[English](README.md) | 中文

此提供者解释显式映射的 shell 工具，并组合固定安全检查、有序部署规则、小型只读集合和有界的独立模型分类。Bash 与 PowerShell 都由配置支持；工具名和参数名都不是内置默认值。

## 配置与行为

`mappings` 指定支持的工具、命令参数和可选意图参数。`primary` 与 `secondary` 选择准确的 `ctx.llm` 提供者和模型路由。超时、输入输出界限、原因和类别上限以及有序命令规则都必须配置。

主机根目录破坏原语和受保护凭据路径在规则或模型调用前被拒绝。无条件 Git 强制推送、远端删除和镜像操作需要询问；`--force-with-lease` 与 `--force-if-includes` 继续接受普通求值。规则对整条命令做类 glob 匹配，最后一个匹配生效，且 allow 规则不能放行包含 shell 元字符的命令。

未匹配命令以零温度和严格 JSON 格式进入主分类器。完整且有界的辅助请求在调用前持久化。主分类器拒绝后获得独立的次分类意见；只有风险低于 50 且双方都不含敏感或破坏类别的 allow 才能覆盖。无效、不可用、失败或超时都变为 `ask`。调用方取消仍是取消。

## 安全行为

诊断只保留有界且清理过的原因和类别。原始命令参数保留在 `tool/call`，不会复制到决策事件。模式匹配刻意保守，不解析完整 shell 语法；固定情况之外由模型分类器处理。

## 模型体验

### 条件授权反馈

#### 模型看到什么

提供者不添加主提示词。执行消费者根据 `tools/pre-execute` 裁决呈现重试或审批反馈。

#### Token 影响

确定的硬拒绝、询问、规则和只读情况不消耗分类 token。其他调用消耗一次辅助请求；主分类器拒绝时再消耗一次独立请求。

#### KV 缓存影响

分类请求使用固定系统前缀和稳定 JSON 字段顺序，有利于辅助缓存复用，且不修改主对话前缀。

## 已知限制和延后工作

- 固定检查覆盖高置信 shell 文本模式，不是所有 shell 方言的 AST。
- 命令超过配置界限时会询问，不会把截断命令交给分类器。
