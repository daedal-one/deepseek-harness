# Access mode hover descriptions

## Acceptance

The Web composer provides concise descriptions for the built-in Read Only, Workspace Write, and Full access modes. Hovering a mode in the open access menu shows its description, and focusing the mode provides the same keyboard-accessible tooltip. Hovering or focusing the closed access control describes the current mode. A host-provided description takes precedence so deployments can accurately explain customized preset behavior.
